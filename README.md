# SYLVARQ website starter

A free, static HTML/CSS/JavaScript starter for the SYLVARQ website.

## Preview locally
1. Extract this folder.
2. Open `index.html` in a modern browser.
3. Edit `index.html` for content, `styles.css` for design, and `script.js` for interactions.

No build tools, paid services, or API keys are required.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new **public** repository named `sylvarq-website`.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
4. Open repository **Settings → Pages**.
5. Under build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. GitHub will provide a `https://YOUR-USERNAME.github.io/sylvarq-website/` address after deployment.

GitHub Pages publishes static files. It does not provide a working contact-form backend. Add a real business email or a form provider only after deciding what contact details to publish. Never put passwords, API keys, or private customer information in these files.

## Before public launch
- Verify the SYLVARQ name and logo are legally available.
- Replace any draft claims with services that have actually been built and tested.
- Add a business contact method you control.
- Add privacy and other required legal notices if collecting visitor information.
- Test on mobile and desktop.
